## 发布

创建公开仓库 `getl-x/getl-x`，将本文件夹里的 `README.md` 与整个 `assets` 文件夹上传到仓库根目录并提交。不要把外层 `getl-x-profile` 文件夹整体套在根目录之外。完成后 GitHub 会在个人主页展示 README。

如果这个仓库已经存在，请保留原有文件，先查看已有 README 再决定合并或替换。

本说明不用上传。压缩包中的文件可解压后直接使用。
