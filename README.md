### 关注的方向

- **日常效率**：少一点重复操作，让记录、提醒和信息整理更轻松。
- **数据自主**：关注隐私、本地处理、离线体验与自托管。
- **使用体验**：在功能之外，也认真打磨界面、交互和部署文档。
