# 项目如何自动加入主页

主页的项目卡片由 `Sync profile projects` 工作流维护。每天北京时间 08:17 左右检查一次公开仓库；GitHub 的定时运行可能稍有延迟。自动更新在 GitHub 上执行，不需要本地电脑开机，也不需要配置额外的 Token。

## 新建项目

1. 在自己的账号下新建一个公开仓库。
2. 填写仓库的 Description（一句话简介），让卡片上的介绍更清楚。
3. 等下一次同步，项目就会加入主页。没有简介也会加入，显示“项目简介待补充”。

自动收录本人拥有的公开仓库，跳过私有仓库、Fork、归档仓库、已禁用仓库及个人主页仓库本身。仓库改名、删除、归档或转为私有后，卡片也会在下一次同步时更新或移除。

已有六个项目按精选顺序展示，并保留定制的文案和图标；其他项目按创建时间从新到旧排列。普通代码更新不会打乱卡片顺序。

## 立即刷新

打开个人主页仓库 `getl-x/getl-x`，进入 **Actions → Sync profile projects → Run workflow**，选择 `main` 并运行。

## 调整展示

编辑仓库根目录的 [profile-projects.json](../profile-projects.json)：

- `excluded_repositories`：填写不想展示的仓库名，例如 `["test-demo", "temporary-project"]`。
- `featured`：按展示顺序配置精选项目，可自定义 `title`、`subtitle`、`description`、`tags` 和 `icon`。精选文案以配置为准，其他项目读取仓库 Description。

修改并提交配置后会自动触发同步。自定义图标放在 `assets/` 下，新项目默认使用通用项目图标。

直接编辑 README 中的介绍、关注方向、技术标签等内容即可；项目卡片在 `<!-- PROJECTS:START -->` 和 `<!-- PROJECTS:END -->` 之间，下次同步会按配置重新生成。

## 运行与维护

仅在卡片内容发生变化时提交 README。每月还会刷新一次 `.github/project-sync-state.json`，记录当月验证状态和公开项目数，让没有新增项目时的定时同步也能保持活跃。读取 GitHub 数据失败时，本次同步会失败并保留已有主页；可以在 Actions 查看记录并重试。

GitHub 会对连续 60 天没有仓库活动的公开仓库停用定时工作流，因此这里加入了每月状态更新。如果曾手动停用工作流，点击 **Enable workflow** 重新开启，再手动运行一次。相关规则见 [GitHub 的 schedule 说明](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)。

本地验证：

```bash
python -m unittest discover -s tests -v
python scripts/update_projects.py
python scripts/update_projects.py --check
```
